# AI Memory Bank CLI

Git-backed long-term memory bank tooling for persistent AI development context.

## Commands

- `ai-sync init`
- `ai-sync doctor`
- `ai-sync compile`
- `ai-sync start`
- `ai-sync checkpoint`
- `ai-sync handoff`
- `ai-sync apply <packet-file>`
- `ai-sync status`

## Install

```bash
python -m pip install -e .
```
